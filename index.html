Understanding Semantic Tags

The <header> element acts as an introductory wrapper containing headings or branding, while the <nav> element is strictly reserved for grouping collections of navigational links.

The <main> tag groups the primary unique topic matter of the page body. Inside it, an <article> defines an independent, self-contained post block that makes complete sense on its own, such as an isolated forum topic or assignment summary log.

Daily Challenge 4: Escaped Characters & Symbol Entities

Displaying direct code strings requires using escaped HTML character entities so the browser reads them as literal text instead of active syntax. Here are the core structural tokens rendered cleanly:

  • The less-than sign symbol token: < (written as &lt;)
  • The greater-than sign symbol token: > (written as &gt;)
  • The ampersand system connector token: & (written as &amp;)
  • The standard placeholder quotation marker: " (written as &quot;)
