Understanding Semantic Tags

The <header> element acts as an introductory wrapper containing headings or branding, while the <nav> element is strictly reserved for grouping collections of navigational links.

The <main> tag groups the primary unique topic matter of the page body. Inside it, an <article> defines an independent, self-contained post block that makes complete sense on its own, such as an isolated forum topic or assignment summary log.

Environment Callout

The <aside> element encapsulates information that is tangentially related to the surrounding main topic flow, like sidebars, callout notes, dictionary lists, or background profiles.

The <footer> defines a closing tray structure housing copyright markings, contact nodes, or license signatures.
